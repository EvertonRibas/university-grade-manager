# University Grade Manager 

A Python-based application to manage and calculate university grades efficiently.

## Sobre o Projeto

Este projeto ajuda estudantes a acompanhar seu desempenho academico calculando medias e gerenciando notas em diferentes materias. Desenvolvido como parte dos meus estudos em Gestao de Tecnologia da Informacao.

## Funcionalidades

- Calculo de Medias: Calcula medias ponderadas automaticamente
- Acompanhamento de Performance: Monitora progresso academico
- Armazenamento de Dados: Salva notas em arquivos CSV
- Geracao de Relatorios: Cria relatorios academicos detalhados
- Verificacao de Status: Verifica status de aprovacao automaticamente

## Tecnologias Utilizadas

- Python 3.x - Linguagem de programacao principal
- Pandas - Manipulacao e analise de dados
- CSV - Formato de armazenamento de dados
