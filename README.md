# University Grade Manager

Sistema para gerenciar notas universitárias em Python.

## Como usar:

1. Execute: python grade_manager.py
2. Adicione matérias e notas
3. Veja seu relatório

## Tecnologias:

- Python
- Pandas

## Estrutura do projeto:

- grade_manager.py - programa principal
- requirements.txt - dependências
- notas.csv - arquivo de dados (criado automaticamente)
