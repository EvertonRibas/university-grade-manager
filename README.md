# University Grade Manager 🎓

A Python-based application to manage and calculate university grades efficiently.

## 📋 About The Project

This project helps students track their academic performance by calculating averages and managing grades across different subjects. It was developed as part of my Information Technology Management studies.

## ✨ Features

- 📊 **Grade Calculation**: Automatically calculates weighted averages
- 📈 **Performance Tracking**: Monitors academic progress
- 💾 **Data Persistence**: Saves grades to CSV files
- 📋 **Reports Generation**: Creates detailed academic reports
- ✅ **Status Verification**: Checks approval status automatically

## 🛠️ Technologies Used

- **Python 3.x** - Main programming language
- **Pandas** - Data manipulation and analysis
- **CSV** - Data storage format
